Meu Projeto

Sensoriamento Remoto: Mapeando a cidade de Adamantina utilizando CBERS-4A

Problema

O projeto tem como objetivo realizar o mapeamento urbano da cidade de Adamantina utilizando imagens de sensoriamento remoto.

O que eu fiz

Realizei o pré-processamento da imagem no software QGIS. Em seguida, criei arquivos para armazenar as amostras e coletei amostras de duas classes: árvores e outros. Treinei os algoritmos Random Forest (RF) e Support Vector Machine (SVM) para classificar toda a imagem.

Como eu fiz

Utilizei uma imagem do satélite CBERS-4A, disponibilizada pelo Instituto Nacional de Pesquisas Espaciais (INPE), para realizar o processamento e a classificação da imagem no QGIS.

Resultado

O projeto alcançou uma acurácia de 86% na classificação da imagem, demonstrando os resultados obtidos com os algoritmos utilizados.
